JAVAD CRAFT — بسته آماده انتشار رایگان با GitHub Pages
======================================================

محتویات:
- index.html: صفحه اصلی سایت و ۱۰۰ دانستنی ماینکرفت
- style.css: ظاهر واکنش‌گرا
- images/: تصاویر بنر و پروفایل
- robots.txt: اجازه خزش موتورهای جست‌وجو

انتشار در GitHub Pages:
1) وارد https://github.com شوید و وارد حساب خود شوید.
2) روی + و سپس New repository بزنید.
3) نام مخزن را دقیقاً این بگذارید: YOUR-USERNAME.github.io
   به جای YOUR-USERNAME نام کاربری GitHub خودتان را بنویسید.
4) مخزن را Public انتخاب کنید و Create repository را بزنید.
5) Add file > Upload files را انتخاب کنید.
6) فایل‌های داخل این پوشه را آپلود کنید؛ خود پوشه Javad_Craft را آپلود نکنید.
   باید index.html در ریشه مخزن دیده شود و پوشه images هم کنار آن باشد.
7) Commit changes را بزنید.
8) در Settings > Pages، اگر لازم بود گزینه Deploy from a branch و شاخه main و پوشه /(root) را انتخاب و Save کنید.
9) پس از چند دقیقه سایت در این آدرس باز می‌شود:
   https://YOUR-USERNAME.github.io/

نمایش در گوگل:
1) پس از فعال شدن سایت، وارد https://search.google.com/search-console/ شوید.
2) گزینه URL prefix را انتخاب کنید و آدرس کامل سایت خودتان را وارد کنید:
   https://YOUR-USERNAME.github.io/
3) روش تأیید HTML tag یا HTML file را طبق دستور همان صفحه انجام دهید.
   اگر Google یک تگ meta داد، آن را داخل بخش <head> فایل index.html قرار دهید و دوباره آپلود کنید.
4) در URL Inspection آدرس صفحه اصلی را وارد کنید و Request Indexing را بزنید.

نکته‌های مهم:
- هاست GitHub Pages و زیردامنه github.io رایگان هستند.
- ظاهر شدن در گوگل فوری و تضمینی نیست؛ ممکن است چند روز یا بیشتر طول بکشد.
- برای دامنه اختصاصی مثل .ir یا .com باید دامنه جداگانه تهیه شود.
- لینک آپارات داخل سایت قرار دارد. دو لینک شبکه اجتماعی دیگر فعلاً جای‌نگهدار هستند و باید با لینک واقعی جایگزین شوند.
- برای امنیت، رمز عبور یا کد ورود GitHub را برای هیچ‌کس نفرستید.
